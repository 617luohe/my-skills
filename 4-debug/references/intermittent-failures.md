# Intermittent Failures

用统计信号处理偶发故障，不要求单次命令必现。

## 最小数据

- 执行次数、失败次数和失败率。
- 时间窗、版本、环境和随机种子（若可得）。
- 请求 ID、关联 trace 或脱敏样本。
- 异常类型、关键状态和发生顺序。

修复前后使用相同工作负载、样本量和筛选条件，并预先写下验收阈值。

## 重复试验

只重复项目已有测试、负载脚本和工具。失败率低时增加预先约定的样本量或延长观测窗，并保留每轮通过、失败和超时结果。

## 时序与并发

- 检查共享状态、异步边界、锁/队列、连接池和资源生命周期。
- 一次只改变一个调度条件、并发度或超时。
- 仅使用项目已批准的竞态检测器。
- 插桩包含关联 ID、状态转换和顺序，并限速或采样。

稳定复现缺失时，可重复的统计差异仍可支持或排除假设。
