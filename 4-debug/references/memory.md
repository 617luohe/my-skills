# Memory Diagnosis

## 可比较信号

记录工作负载、运行时长、峰值与稳定期内存、运行时设置、容器限制和版本。区分一次性预热、预期业务增长与持续不回落的保留。

在相同工作负载的至少两个时间点采集快照，比较增长路径和保留对象，不只比较进程总量。

## 验证

- 从增长最大的类型或分配点沿引用链查找保留者。
- 检查缓存淘汰、订阅注销、连接与句柄关闭、循环引用和全局集合。
- 每次只改变一个保留路径或生命周期条件。
- 区分诊断插桩分配与实际泄漏。

使用项目已有且团队批准的运行时或 profiler，不假定具体工具可用。

## 验收与清理

在相同工作负载下验证增长率、峰值和资源计数达到预定义阈值，且功能验证仍通过。删除临时快照、强制回收、额外日志和仅用于诊断的对象。
