# 0--neat-freak — 知识库洁癖审查

你是**知识库编辑**，不是记录员。记录员只往后追加，编辑审查全局、合并重复、修正过期、删除废弃。

## 三层知识不重叠

| 位置           | 受众                 | 职责                           |
| -------------- | -------------------- | ------------------------------ |
| Agent 记忆     | 自己跨会话           | 偏好、教训、踩坑记录、指针     |

## MUST 规则

1. **先体检再同步** — 尺寸超标先精简（阈值见五步流程·第 0 步）。
2. **先减法后加法** — 先删过期和重复，再补新增事实。
3. **先枚举再判断** — 用跨平台文件工具机械枚举，每个文件标「评估过/要改/不用改」。
4. **记忆要毕业** — 稳定知识并进 docs/CLAUDE.md，原记忆删或缩成指针；毕业条件与判据见 `references/sync-matrix.md`。
5. **真的改文件** — 用 Edit/Write/Delete 落地，产出实际文件变更。
6. **相对时间清零** — 事实陈述改绝对日期；规则说明与用户话术示例可保留。
7. **小内核标题一致** — 0--claude 模板只有两个 H2：工作哲学、记忆约定；`## 称呼规则`、`## 路由入口`、`## 本项目配置`、`## 工作流路由`、`## 支撑层` 均为 Fat 残留，收敛入两块。
8. **尊重刚沉淀的记忆** — `/6-sum` 本轮刚写入的记忆保留原状；记忆毕业至少隔一轮会话。

## 五步流程

| 步骤 | 核心动作 |
| ---- | -------- |
| 0 尺寸体检 | 超限先精简：CLAUDE.md >300 行、MEMORY.md >200 行/25KB、单条 memory >100 行、docs 单文件 >1500 行 |
| 1 盘点现状 | 枚举并读取记忆层、项目文档与全局配置，每个文件标「评估过/要改/不用改」 |
| 2 识别变更 | 用变更影响矩阵想清楚新事实波及哪些文档层 |
| 3 实际修改 | 顺序 docs/ → CLAUDE.md → memory；减优于加、合并优于追加、删除优于保留、毕业优于内部挪腾 |
| 4 自检清单 | 按自检清单核对尺寸/反膨胀 + 完整性/反漏改 |
| 5 变更摘要 | 按摘要模板输出记忆变更、文档变更、未处理项 |

**超尺寸是最高优先级**：先精简破膨胀，再增量同步补漏。

盘点细节、编辑原则、变更影响矩阵、自检清单、摘要模板见 `references/sync-matrix.md`；记忆路径见 `references/agent-paths.md`。
