# 会话交接模板

保存到 `docs/handoff/handoff-<topic>.md`：

```md
# Handoff: <会话主题>

## 当前状态
做到了哪一步、什么还没做。

## 已做出的决策
- [决策 1] — 为什么

## 未决事项
- [待定事项]

## 下一步行动
1. [行动] → 建议使用的技能

## 脱敏
交接文档不含 API key、密码、令牌与个人可识别信息；已存于 spec/plan/ADR/commit 的内容用路径引用，不重复贴正文。

## 引用
- PRD: [路径]
- 相关文件: [路径]
```

## 收尾输出摘要

```
## 会话收尾完成
### 修改总结 / 经验沉淀 / 项目结构整理 / 交接
（各段一行摘要）
```
