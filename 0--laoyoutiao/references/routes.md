# 意图路由与异常

## 意图路由

| 用户意图 | 路径 |
|----------|------|
| 查看当前状态、待交付项 | 状态查看 |
| 指定某模块/能力切换 | 精确切换 |
| 询问这次交什么、快到节点、无参数调用 | 交付建议 |
| 只要求交付说明 | 说明生成 |
| 明确要求初始化，且无可复用框架 | 初始化默认适配器 |

模糊时走「交付建议」。

## 异常处理

| 场景 | 行为 |
|------|------|
| 已有框架但无 Python 注册表 | 从 schema/调用点建立适配契约 |
| 多个事实来源冲突 | 停止写盘，推荐生产代码实际读取的来源 |
| 配置引用已删除状态 | 展示修复预览，确认后修复 |
| 原框架不能表达交付节奏 | 推荐最小兼容改造 |
| 无候选 | 输出「无待交付升级」并退出 |
| 校验失败 | 报告命令、错误摘要、实际写入内容 |
