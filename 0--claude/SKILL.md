# 0--claude — CLAUDE.md 初始化器

luohe，我来处理项目的 CLAUDE.md。

**设计**：CLAUDE.md 常驻称呼 + 工作哲学 + 路由入口 + 记忆约定 + 项目配置。

**唯一模板源**：`references/template.md`。改规则正文只改模板一处。

## MUST 规则

1. **模板是唯一源** — 正文从 `references/template.md` 读取。
2. **非破坏式注入** — 已有内容不动，只补缺失块。
3. **结构化检测** — 按 H2 精确匹配（见下表）；`## 路由入口` 为必选块，替代旧版 `## 工作流路由` + `## 支撑层`。
4. **Fat 迁移** — 若存在旧版 `## 工作流路由`（含路由表）或 `## 支撑层`：删除这两块，保留或注入 `## 路由入口`；**保留**已有 `## 工作哲学` 正文（若完整）。

## 规则块清单

| 块         | 检测 H2           | 说明                         |
| ---------- | ----------------- | ---------------------------- |
| 称呼规则   | `## 称呼规则`     | template 同名段              |
| 工作哲学   | `## 工作哲学`     | 输出(Caveman) + 改动(Karpathy 四则) + 设计(Vercel) |
| 路由入口   | `## 路由入口`     | 指针，无路由表               |
| 记忆约定   | `## 记忆约定`     | 触发/写入/检索/边界          |
| 项目配置   | `## 本项目配置`   | vault 路径、命令速查         |

## 流程

### 1. 问候 + 取项目名

称呼 luohe；取当前目录名替换 `{project-name}`。

### 2. 判断路径

#### 分支 A：无 CLAUDE.md

读 template → 替换项目名 → 写入 `./CLAUDE.md` → 可选写 AGENTS 指针（[references/agents-pointer.md](references/agents-pointer.md)）。

#### 分支 B：已有 CLAUDE.md

1. 若有 `## 工作流路由` / `## 支撑层` → 删除（Fat 清理）；**保留** `## 记忆约定`
2. 按上表检测缺失块 → 从 template 切出并注入（顺序：称呼规则 → 工作哲学 → 路由入口 → 记忆约定 → 本项目配置）
3. 合并旧版 `## 默认知识库` / `## 命令速查` 实质内容进 `## 本项目配置`
4. 五块齐全且无 Fat 残留 → 可告知无需改动

## 什么时候用

- 新项目开张（通常接在 `/0-启动` 之后）
- 补齐缺失规则块，或从 Fat 版（含路由镜像表）迁移

## 完成后

用户直接说需求；规模不明先 `/0-询问luohe`。中大功能默认 `/1-规划`。
