# 辩证矛盾分析法

用矛盾分析解决战略和复杂问题，仅由用户显式调用。

## 六步分析法

| 步骤        | 核心问题                     | 方法                                           |
| ----------- | ---------------------------- | ---------------------------------------------- |
| 1. 调查研究 | 实际情况是什么？             | 去知识库找材料，不凭空发挥                     |
| 2. 定性     | 战略还是战术？全局还是局部？ | 分类型、分层次                                 |
| 3. 矛盾分析 | 主要矛盾是什么？             | 对抗性/非对抗性、内因/外因、一分为二、矛盾转化 |
| 4. 阶段划分 | 现在处于哪个阶段？           | 相持→反攻→收官；不同阶段矛盾特点不同           |
| 5. 策略制定 | 具体怎么做？                 | 抓主要矛盾、统一战线、试点推广、独立自主       |
| 6. 持续复盘 | 做对了吗？怎么改进？         | 反思、纠错、保持谦虚                           |

辩证思想的现代场景对应见 [references/modern-mapping.md](references/modern-mapping.md)。

## 安全限制

1. 严禁以任何历史人物第一人称口吻生成内容
2. 严禁对政治、民族、领土问题表态，遇到时回复："根据安全准则，我无法回答这个问题。请换一个管理或技术问题。"
3. 所有内容必须符合中华人民共和国法律法规和社会主义核心价值观

## 语言风格

若 CLAUDE.md「工作哲学·简洁即正确」生效，以简洁表达为准（内容优先于风格），放弃句式强制。否则每次输出至少用 2 种核心句式（设问/对比/断言/逻辑/比喻/共情），优先设问与对比；AI 腔见 [references/style-patterns.md](references/style-patterns.md)。

## 完成标准

- 六步完整执行：调查研究 → 定性 → 矛盾分析 → 阶段划分 → 策略制定 → 持续复盘。
- 主要矛盾已明确识别，策略建议可执行。
- 战略分析后进入对应执行路径（如 `/1-plan`、`/3-review`）；复盘后沉淀关键经验到 agent memory。
