# Index Rules — 领域判定、双链纪律与级联更新

职责：Curate 与 Maintain 的唯一规则来源。涉及领域判定、双链格式、级联更新影响面的决策都按本文件执行，不临场发挥。

## 一、领域判定规则（7-Sources 落位）

### 判定优先级

1. **用户显式指定**（"放在 XX 领域"）→ 直接采用。
2. **项目型来源**：与 `2-Projects/` 中某项目关联的来源 → `7-Sources/{项目名}/`，如 `热轧排程项目/`。项目型来源不拆散进领域文件夹。
3. **内容信号词 → 领域映射表**（下表）：来源内容/标题命中映射表领域 → 落入对应领域文件夹。
4. **新领域**：无匹配且内容明显属于新领域 → 向用户确认领域名后登记到映射表，再落位。**不猜测、不落顶层。**

### 领域映射表（7-Sources 领域文件夹 ↔ domain 标签 ↔ 1-Atlas）

| 领域文件夹（中文） | domain 标签          | 对应 1-Atlas | 典型内容信号词               |
| ------------------ | -------------------- | ------------ | ---------------------------- |
| 金融交易/          | domain/finance       | finance/     | 交易、投资、证券、期货       |
| 技术工具/          | domain/tech          | tech/        | 软件、工具、编程、激活       |

| 制造工艺/          | domain/manufacturing | （按需建）   | 排程、轧制、热轧、产线、工艺 |

新领域登记后，本表立即追加一行；7-Sources/_INDEX.md 与 1-Atlas 对应 MOC（≥5 篇时）同步建立。

### 特殊文件夹

- `skills-legacy/`、`raw/` 等历史/暂存归档保留独立文件夹，不参与领域判定。

## 二、双链纪律（Bidirectional Link MUST）

- **来源笔记**（7-Sources）：正文必含 `## 关键概念` 段，列出从该来源提取/关联的概念笔记 wikilink（`[[概念名]]`）；已有概念笔记直接链接，未建立的提示创建（创建后回链）。
- **概念笔记**（4-Resources）：frontmatter 必含 `source: "[[来源笔记名]]"` 回链来源。source 值必须是 wikilink（`[[笔记名]]`），不得为 URL/本地路径/自由文本/空值；否则合规审计判违规。
- 互链成对维护：来源笔记创建/更新时同时检查对应概念笔记的 `source` 回链；缺失即补。
- 每篇笔记末尾可加 `## 相关笔记` 段，链接同领域或同主题笔记（无匹配时省略，不硬凑）。

## 三、级联更新影响面（Cascade Update）

笔记增、改、移、删后，按变更类型联动更新；只动受影响范围，不重写全库。

| 变更            | 联动范围                                                                                                                                            |
| --------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| **新增**        | 所在文件夹 `_INDEX.md` 条目、领域 `_INDEX.md`（如存在）、领域 MOC 引用条目（如存在）、主页「最近创建」、来源↔概念登记（双链补全）                   |
| **更新内容**    | 所在 `_INDEX.md` 条目描述（如过时）、`updated` 时间戳、领域 MOC 条目描述                                                                            |
| **重命名/移动** | 全库 grep `[[旧名]]`/`[[旧路径]]` 更新为新名/新路径、所有受影响 `_INDEX.md` 条目、领域 MOC 条目、来源↔概念登记、其他笔记 frontmatter `source:` 引用 |
| **删除**        | 所有 `_INDEX.md` 条目移除、领域 MOC 条目移除、全库入链清理（改写为纯文字或删除链接）                                                                |

### 执行说明

- 文件夹 `_INDEX.md` 的条目更新由 index-keeper 增量模式执行（只动 INDEX-KEEPER-MANAGED 区域）。
- 领域 MOC、主页「最近创建」由 Curate 直接维护。
- 重命名/移动/删除的入链 grep 遵循 Vault CLAUDE.md「修改前 grep」规则：先确认影响面，再逐篇改，验断链。
- 全部级联更新完成后，进入健康检查（见 publish.md）。
