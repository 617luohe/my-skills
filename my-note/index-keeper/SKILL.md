# index-keeper — 索引维护

自主维护每个一级文件夹与领域文件夹的 `_INDEX.md`（结构性导航索引，非概念地图）。INDEX 定位 = "文件夹里有什么"（MOC 等概念地图由 noteall Curate 的维护任务承担）。

## 一、INDEX 统一结构

每个 `_INDEX.md` 包含：frontmatter（title/tags/created/updated/auto-indexed）→ 一句话描述 → 统计区 → 内容导航 → 维护日志。

### 各文件夹导航结构定制

| 文件夹                  | 导航内容                                             |
| ----------------------- | ---------------------------------------------------- |
| 0-Inbox/                | 待处理队列表 + 处理统计（本周新增/处理/积压）        |
| 1-Atlas/                | MOC 注册表（按 domain 分组列出所有 MOC）             |
| 2-Projects/             | 项目看板（活跃/暂停/已完成，含优先级+截止日期+进度） |
| 3-Areas/                | 责任域仪表盘（领域+最后回顾+状态+入口笔记）          |
| 4-Resources/            | 知识领域树（按 domain 分组，含笔记数）               |
| 5-Journal/              | 日记结构 + 近期活跃表（日期+日记+心情+关键事件）     |
| 6-People/               | 人物目录（按 relationship 分组：同事/朋友/…）        |
| 7-Sources/              | 来源目录（按领域分组：金融交易/技术工具/…）          |
| 7-Sources/{领域文件夹}/ | 领域来源清单（该领域 ≥5 篇时建立）                   |
| raw/                    | 待处理文件表 + 处理统计（总/本周新增/超7天未处理）   |

使用 `8-Templates/tpl-INDEX.md` 模板创建新 INDEX。**统计值（数量/最近新增等）在每次更新时静态重算并写死**——索引必须纯文件系统可读，不依赖 dataview 等 Obsidian 插件。

## 二、工作模式

| 模式             | 触发                                      | 行为                                                         |
| ---------------- | ----------------------------------------- | ------------------------------------------------------------ |
| 增量更新         | noteall Curate 级联更新调用（指定文件夹） | 只更新指定文件夹，只处理变更部分；领域文件夹新文件自动登记   |
| 缺失补全         | noteall Maintain / 手动                   | 仅为无 `_INDEX.md` 的一级/领域文件夹创建初始 INDEX           |
| 健康检查（轻量） | noteall Publish 收尾前                    | 断链、孤岛、INDEX 缺失条目、统计过期；报告不阻塞             |
| 健康检查（完整） | noteall Maintain / 手动                   | 全库扫描：缺失 INDEX、失效链接、缺失条目、过期描述、统计过期 |
| 全量更新         | `/my-note/index-keeper` / noteall Maintain    | 扫描所有一级与领域文件夹，生成/更新所有 _INDEX.md            |

### 增量更新自动触发时机

- noteall Curate 级联更新后

## 三、安全规则

- `<!-- MANUAL -->...<!-- /MANUAL -->` 区域完全不碰
- 内容导航只增不删（确认失效链接除外）
- 每次修改记录维护日志
- 全量更新前展示变更摘要，确认后写入
- 只读写 `_INDEX.md`，不碰其他文件（级联更新中的 MOC/主页维护由 noteall Curate 承担）

## 四、输出

更新后输出简短报告：哪些文件夹更新了，哪些条目增加/删除，需关注的问题。健康检查输出检查项结果表。
