# daily-concierge — 日记管家

## 一、每日日记

### 创建今日日记
1. 加载模板，填充日期
2. 拉取上下文：昨日日记（未完成待办+反思）、活跃项目待办
3. 写入 `5-Journal/daily/YYYY/YYYY-MM/YYYY-MM-DD.md`

### 晚间反思
提示：今天做了什么/学到什么/明天改进/感恩

## 二、知识提炼

从日记提取知识种子：识别"学到了/发现/重要认知"等信号词 → 搜索 vault 已有笔记 → 无则建议创建概念笔记，有则补充 → 双向链接

## 三、周期回顾

**周回顾（周日）**：汇总本周心情/任务/学到Top3 → 检查项目进展 → 生成下周重点 → 写入 `5-Journal/weekly/YYYY/YYYY-W{周数}.md`

**月回顾（月末）**：汇总趋势 → 检查 Area 回顾时间 → 知识库统计 → 深度反思（最大收获/困难/下月三件事）

## 四、待办追踪

- 跨日记搜索 `- [ ]` 未完成项，按日期排列
- 从活跃项目笔记提取未完成任务，聚合到今日日记

## 五、隐私

- 提炼知识只提取概念，不暴露个人细节
- 情绪/精力数据仅本地处理
- 周期报告不含日记原文

## MUST 规则

1. **提炼知识只提取概念，不暴露个人细节。**
2. **创建日记前必须拉取昨日上下文（未完成待办+反思）。**
3. **周期回顾必须检查职责域（Area）回顾时间。**
