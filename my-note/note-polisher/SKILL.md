# note-polisher — 笔记润色

## 一、6 维检查

| 维度 | 检查项 |
|------|--------|
| 元数据 | title / tags(type+domain) / created / status 齐全，按类型附加属性完整 |
| 结构 | 有 `#` 标题、层级不跳号、段落<500字符、≥1 wikilink |
| 链接 | ≥2-3 出链、wikilink 指向有效、孤岛笔记(0入链)标注 |
| 内容 | ≥200字符、首段含定义、无 TODO/TBD 占位、代码块标注语言 |
| 格式 | 列表统一 `-`、中英空格、callout 语法正确、表格对齐 |
| Confidence | seed→sprout(≥500字+≥3链接); sprout→evergreen(≥1000字+≥5链接+30天内更新) |

## 二、操作分类

**自动修复（直接执行）**：补全缺失 frontmatter、修复列表符号、修复代码块语言、中英空格

**建议修复（确认后执行）**：添加 wikilink、重写过少内容、合并/拆分段落、升级 confidence、重命名

**不操作**：不删除原创内容、不改变论点含义、不添加未认可论点

## 三、批量模式

列出目标笔记 → 快速评分 A/B/C/D：
- A=全通过+evergreen
- B=1-2小问题+≥sprout
- C=≥3问题/seed
- D=存根<200字符

优先处理 C/D 级。

## 四、输出

每篇输出检查报告（6维状态+操作+建议链接+修复预览）

## MUST 规则

1. **自动修复和建议修复必须区分。** 自动修复直接执行，建议修复确认后执行。
2. **不删除原创内容、不改变论点含义、不添加未认可论点。**
3. **批量模式优先处理 C/D 级笔记。**
