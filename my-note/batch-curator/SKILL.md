# batch-curator — 批量知识整理

自动分析 + 批量确认模式：扫描 → 分析 → 计划（一次性确认）→ 执行 → 索引 → 归档。

## 一、6 阶段流水线

### ① Scan — 扫描
递归扫描目标文件夹（默认 `raw/`），识别可处理文件。支持 `.md` `.txt` `.csv` `.json` `.pptx` `.docx` `.pdf` `.xlsx` `.py` `.js` `.ts` `.png` `.jpg`。跳过隐藏文件、系统文件。

### ② Analyze — 分析（只分析不写入）
每文件分析以下维度：

- **笔记类型推断** — 优先级：frontmatter > 文件名信号词 > 内容结构 > 默认 resource
- **领域推断** — 关键词匹配 > 路径推断 > 已有笔记关联 > 默认 uncategorized
- **概念提取** — 每文件 3-8 个关键术语（专有名词/方法名/框架名优先）
- **去重检查** — 标题相似度 >80%→重复；50-80%→相关

每文件输出分析卡片：类型、领域、关键概念、目标目录、已有相关笔记、去重状态。

### ③ Plan — 生成计划（一次性确认）
汇总分析结果，展示表格（文件→笔记类型→目标路径→领域→操作）。用户可在此调整任何字段。

### ④ Execute — 批量生成
- **新笔记**：标题 + frontmatter（title/tags/created/status:draft）+ 自动 wikilink + `## 相关` + `## 来源`
- **更新已有**：追加不覆盖，保留手动属性，更新 `updated`，展示 diff 确认

### ⑤ Index — 更新索引
- 已有 MOC → 追加新笔记链接
- 某领域 ≥3 篇且无 MOC → 建议创建
- 原则：只增不删，保持原有组织结构

### ⑥ Archive & Report — 归档 + 报告
- 原始文件移至 `7-Sources/{project}/`
- 输出处理报告：扫描/新建/更新/归档/跳过 统计 + 新建文件列表 + MOC 变更 + 后续建议

## 二、边界处理

| 情况 | 行为 |
|------|------|
| 空文件夹 | 提示无文件 |
| >20 个文件 | 建议分批 |
| 文件读取失败 | 跳过，标记未处理 |
| 用户取消 | 展示已完成进度，支持继续/回滚 |
| 标题冲突 | 相似度 >80%→跳过；50-80%→加序号+双向链接 |

## 三、安全规则

- 不自动删除：始终归档不删除原文件
- 写入前确认：阶段③必须确认
- 只追加不删除：更新已有笔记时保留所有原有内容
- 冲突不跳过：标题冲突/去重相似时暂停询问
- AI 推断内容标注 `> [!ai-guess]`

## MUST 规则

1. **计划阶段（③）必须一次性展示全部变更，等待用户确认。** 不逐项确认。
2. **只追加不删除。** 更新已有笔记时保留所有原有内容。
3. **>20 个文件必须建议分批。** 避免单次处理过多。
4. **原始文件始终归档到 7-Sources/，不删除。**
