# concept-atomizer — 概念原子化

将长篇笔记拆解为相互关联、可独立引用的原子概念笔记。

## 一、原子化标准

满足以下才独立成笔记：可定义（一句话说清）、可引用（其他笔记可能需要链接）、可独立学习（不需上下文）、非平凡（非琐碎信息）。

反例：过渡段落、纯举例、已有笔记重复。

## 二、拆解流程

加载笔记 → 识别结构 → 提取候选概念 → 每个概念：判断标准+搜索 vault 去重+命名 → 生成精简笔记（frontmatter + 一句话定义 + 2-5要点 + `source: [[原笔记]]`）→ 概念间互链 → 创建/更新 MOC → 原笔记头部插入 `> [!abstract] 本文涵盖的概念` 索引

原笔记正文保留不动，作为叙事版参考。

## 三、去重策略

| 情况 | 策略 |
|------|------|
| 高度重叠 | 引用已有概念，追加 `## 补充视角` |
| 相似不同角度 | 分别保留，互设 `## 相关` 链接 |
| 已有笔记质量低 | 新笔记替换，旧笔记精华迁移后归档 |

## 四、批量模式

列出目标目录笔记 → 按长度排序（最长优先）→ 逐篇拆解 → 输出批量报告。≥5 篇同领域新笔记时建议创建 MOC。

## MUST 规则

1. **每个候选概念必须检索 vault 去重。** 不创建重复概念笔记。
2. **原笔记正文保留不动。** 仅在头部插入概念索引。
3. **生成的概念笔记必须标注 `source: [[原笔记]]`。**
