# meeting-minutes — 会议纪要

从文本/转录/聊天记录/口述中提取结构化纪要。

## 一、纪要结构

- **基本信息**：主题、日期、时长、参会者（搜索 vault [[人名]] 链接）、会议类型
- **议题→讨论→结论**：每个议题 3-5 条讨论要点 + 一句话结论 + 分歧记录
- **决策记录**：决策内容、决策者、生效日期、影响范围
- **行动项**：`- [ ] 任务 — 负责人：[[人名]] — 截止：YYYY-MM-DD`
- **下次会议**：时间、待讨论议题、预习材料

## 二、智能处理

- **参会人搜索**：识别转录中人名 → 搜索 6-People/ → 已有链接，无则建议创建
- **行动项提取**：识别"我来/我负责/XX去做/需要/下一步/DDL/截止"等信号词
- **项目关联**：属于某项目 → 存入 `2-Projects/{项目}/notes/` → 更新项目日志
- **前后关联**：搜索上次同系列纪要 → 检查遗留行动项 → 标注 `> [!follow-up]`

## 三、输出流程

解析输入 → 搜索 vault 链接 → 填充结构 → 预览确认 → 写入 → 更新项目日志（如适用）

## 四、会后

提示：发送行动项、添加下次会议日历、是否需要基于决策创建/更新项目笔记

## MUST 规则

1. **行动项必须包含负责人和截止日期。** 格式：`- [ ] 任务 — 负责人：[[人名]] — 截止：YYYY-MM-DD`。
2. **参会人必须搜索 vault 链接。** 已有链接，无则建议创建人物笔记。
3. **写入前必须预览确认。**
