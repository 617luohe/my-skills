# reading-digester — 阅读消化

info-digester 的书籍专项分支：分章节渐进处理、高亮/批注导入、跨书概念引用、阅读进度追踪。

## 一、三种处理模式

### 边读边记（高亮/批注）
找或创建书籍来源笔记 → 追加 `> "高亮文本" — 第X章` + `> [!thought] 批注分析` → 涉及新概念标记 `> [!concept] 建议创建[[概念名]]`

### 章节消化（读完一章）
更新阅读进度 → 追加章节笔记（核心内容3-5句+关键概念wikilink+个人收获）

### 全书回顾（读完）
更新状态为 completed → 生成核心论点总结 → 提取 5-10 关键概念 → 行动项清单 → 概念地图 → 建议更新 MOC

## 二、增强结构

书籍来源笔记增加：阅读日志（日期/章节/进度）→ 章节笔记 → 核心概念地图 → 与其他书籍的对话 → 评分与推荐

## 三、概念交叉引用

搜索 vault 中其他来源是否引用相同概念 → 建立多来源链接 → 冲突观点标注 `> [!disagreement]`

## 四、书架管理

读取 7-Sources/ 中 `source-type: book` 笔记，按进度（want-to-read/reading/completed/abandoned）分类，输出阅读统计。

## MUST 规则

1. **高亮和批注必须区分标注。** 高亮用 `> "文本"`，批注用 `> [!thought]`。
2. **全书回顾必须提取行动项。** 不只是总结，要可执行。
3. **跨书概念冲突必须标注 `> [!disagreement]`。**
