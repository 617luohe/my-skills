# 0--explore — 深潜探索引擎

把"模糊种子 + 预算 + 时长"变成一场多轮、多角度、自主收敛的探索，最终输出结构化探索报告，供 `/1-规划` 决定是否落地。

## 输入（运行时由用户给）

- `seed`：模糊方向，如"对 XX 体系进行优化"（可以非常模糊，阶段 0 负责展开）
- `budget`：API 调用次数预算，默认 1000，**硬上限不可超**
- `deadline`：时长，默认 5h
- 可选：禁区、必看维度、价值偏好（权重）

## 铁律

1. **完全自主**：中途不打断用户。机制保证"不重复、有收敛、有账本"；探索质量上限在线程与合成器的判断力。
2. **预算天花板**：硬上限不可超；目标是尽量把预算花在刀刃上，而不是省着不用。
3. **状态全落盘**：写 `docs/explore/<run-id>/`，崩溃/断上下文可续跑，不靠对话记忆。
4. **探索只出报告**：线程不得改主代码库；一切发现回发现池，改动建议留给 `/1-规划`。

## 阶段 0 — 种子展开（1 次合成调用）

把 seed 展开成三样并写入 `state.md`：

1. **目标解读**：seed 的几种合理解读 + 假设清单（每条标"假设，未验证"）
2. **探索维度树**：初始地图格子（每格 = 一个可探索维度/子方向），写入 `map.md`
3. **价值标准**：5 轴权重（默认 惊喜度 0.3 / 杠杆 0.25 / 关联度 0.15 / 置信度 0.15 / 对齐度 0.15，可覆盖）

然后跑**探针线程**校准 `factor`（见 `references/budget-rules.md`）。

## 主循环（每轮 5 步，详规见 `references/loop-protocol.md`）

### 1. PLAN — 生成当轮方向（K 默认 6）

- 配比：约 80% 锚定种子（加深 top-2 高价值方向 + 探测未探索格子）+ 20% wildcard（自由探索相邻领域）
- 每线程一张**方向卡**：`方向ID | 问题 | 要收集的证据 | 声明独占的格子 | 返回格式`
- 并发互斥：两个线程不得声明同一格子

### 2. FAN-OUT — 并行派 K 个线程

- 用 Agent 工具并行派 `researcher` 型线程（只读，不改文件）
- 每线程只领方向卡，返回**发现卡片**：`{发现 | 证据(文件:行 或 URL) | 置信度 | 关联维度 | 自报工具调用数}`

### 3. SYNTHESIZE — 汇总打分

- 收集发现卡片 → 对照探索地图去重 → 按价值标准 5 轴打分（`references/scoring.md`）
- 更新 `map.md`（格子状态：未探索/已探测/深入/死胡同/有希望）
- 决定：加深哪些、剪枝哪些、新增哪些格子（新发现衍生的子方向）
- 写入 `findings.md`（A/B/C 分级）

### 4. CHECKPOINT — 状态落盘

- 每轮结束写：`state.md` / `findings.md` / `map.md` / `ledger.json` / `PROGRESS.md`
- 上下文压力检测：接近极限 → 干净停靠 + 给续跑指引（`references/resume.md`）

### 5. BUDGET — 记账与再分配

- `spent_estimate += 线程数 × factor + 合成开销`（`references/budget-rules.md`）
- 剩余 < 预留线 → 收敛；否则按剩余预算倒推下轮线程数
- 时间检查：剩余 < 15% deadline → 不再开 wildcard，转入收敛

## 收敛

满足任一即停止：**预算触底 / 连续 2 轮无新 A 级发现 / 到 deadline**。

由 findings + map 生成最终报告 `report.md`（模板见 `references/report-template.md`）。

## 完成标准（必须满足）

- 报告五层齐全：执行摘要 / 探索地图 / 分级发现（含证据链）/ 预算账本 / 下一步推荐
- 探索地图覆盖全部已探维度，死胡同也记录"为什么死"
- `ledger.json` 记录：总预算、估算消耗、轮数、线程数、factor
- 所有 A 级发现可追溯到证据（`文件:行` 或 URL）
- 若中途停靠，`PROGRESS.md` 写清续跑指引

## 交接

- 报告放 `docs/explore/<run-id>/report.md`
- "下一步推荐"直接对接 `/1-规划`（决定哪些方向落地）；若要立即修复探索发现的问题，走 `/3-检查`
- 收尾沉淀走 `/6-最后整理`
