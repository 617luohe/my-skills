# 评分尺 — 5 轴价值评分 + A/B/C 分级

## 五轴定义（每轴 1-5 分）

| 轴     | 权重(默认) | 1 分           | 5 分                                       |
| ------ | ---------- | -------------- | ------------------------------------------ |
| 惊喜度 | 0.30       | 常识，人尽皆知 | 推翻一个明确假设，或暴露未预期的盲区       |
| 杠杆   | 0.25       | 无关紧要的细节 | 小改动 → 大收益（性能/成本/质量量级提升）  |
| 关联度 | 0.15       | 孤立           | 与多个已有发现互相印证/衍生新方向          |
| 置信度 | 0.15       | 猜测，无证据   | 有可复核证据（`文件:行` / URL / 实测数字） |
| 对齐度 | 0.15       | 偏离种子目标   | 直接服务于种子目标                         |

权重可被用户覆盖（`state.md` 的价值标准）。

## 打分规则

1. 每个发现逐轴给分（整数 1-5），加权求和得总分：`总分 = Σ(轴分 × 权重)`。
2. 同一发现跨多轴给分时，依据是证据强度，不是措辞。
3. 打分在 SYNTHESIZE 步骤由主流程统一执行（不交给线程自评，防自夸）。

## 分级标准与处置

| 等级 | 总分区间 | 附加条件   | 处置                   |
| ---- | -------- | ---------- | ---------------------- |
| A    | ≥ 4.0    | 置信度 ≥ 4 | 报告正文；下轮加深验证 |
| B    | 3.0–3.9  | —          | 报告附件；可加深       |
| C    | < 3.0    | —          | 记入 map 备注；不加深  |

**边界规则**：

- 置信度 < 4 的发现**不得**评为 A 级（证据不足，哪怕总分高）。
- A 级发现必须在 `findings.md` 有完整证据链（发现 → 证据 → 来源）。
- 死胡同也记录：格子 + 尝试过的角度 + 为什么打不开（防止下轮重探）。

## 连续 2 轮无新 A 级 → 收敛

收敛前做最后一次"未探索格子扫描"：若仍有高潜未探索格且预算允许，先补一轮探测；否则收敛。
