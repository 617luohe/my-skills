# 循环协议 — 每轮 5 步的详细指令

## 1. PLAN — 生成当轮方向

**输入**：`map.md`（格子状态）、`findings.md`（分级发现）、`state.md`（种子解读+价值标准）。

**选方向规则**（K=6 默认）：

| 类型     | 数量 | 来源                               | 说明                           |
| -------- | ---- | ---------------------------------- | ------------------------------ |
| 加深     | 2    | findings 里 A/B 级中价值最高的方向 | 深挖：进一步验证、量化、找边界 |
| 探测     | 3    | map 里"未探索"格子                 | 广度覆盖，每次探测新维度       |
| wildcard | 1    | 相邻领域/未探索格                  | 自由探索，允许偏离种子         |

**方向卡模板**（每个线程领一张）：

```text
方向ID: D-NN
问题: <这轮要回答的一个具体问题>
要收集的证据: <至少 N 条可核实证据：文件:行 / URL / 实测数字>
声明独占的格子: <map 格子 ID，与其他线程不得重叠>
返回格式: 发现卡片
```

**互斥规则**：两个线程不得声明同一格子；wildcard 只能声明"未探索"格。若 K 个格子不足，减少线程数而非重复。

## 2. FAN-OUT — 并行派线程

- 用 Agent 工具并行派发 `researcher` 型线程，`model` 不显式指定（吃全局便宜默认）。
- **线程 brief 必须包含**：
  - 方向卡全文
  - "只读调研，**不修改任何文件**"
  - "返回时用发现卡片格式：`{发现 | 证据(文件:行 或 URL) | 置信度(1-5) | 关联维度 | 自报工具调用数}`"
  - "自报工具调用数 = 本次读取/搜索/执行命令的总次数（用于预算校准，如实报）"
- 线程并行派发后等待全部返回再进入 SYNTHESIZE。

## 3. SYNTHESIZE — 汇总打分

1. **去重**：同一格子/同一发现的重复结论只保留证据最强者，其余标注"重复，见 D-xx"。
2. **打分**：每个发现按价值标准 5 轴打分，加权得总分（`scoring.md`）。
3. **更新地图**：
   - 探测过的格子 → "已探测"；有 A/B 级发现 → "有希望"；打不开或无价值的 → "死胡同"（记原因）
   - "有希望"格子经加深轮验证后 → "深入"
   - 高价值方向衍生新子方向 → 新增格子（"未探索"）
4. **决策**：
   - 加深：总分最高的 1-2 个"有希望"方向下轮加深
   - 剪枝：连续 2 轮无新发现的方向从"有希望"移入"死胡同"
   - 新增：新衍生的未探索格优先给 wildcard
5. **写入** `findings.md`（分级 A/B/C，每级标注证据链）。

## 4. CHECKPOINT — 状态落盘

每轮结束**必须**写入（全部原子写完再进下一轮）：

- `state.md`：轮次、当前活跃方向、已剪枝方向及原因
- `findings.md`：全部去重后分级发现
- `map.md`：格子状态全量
- `ledger.json`：预算账本更新
- `PROGRESS.md`：本轮进度 + 下一步动作（续跑入口）

**上下文压力检测**：若感知上下文接近极限（大量工具输出、对话过长），执行干净停靠：
写 `PROGRESS.md`（含续跑指引），然后向用户报告 run-id 与停靠原因，不硬撑。

## 5. BUDGET — 记账与再分配

按 `budget-rules.md` 执行。关键决策点：

- 下轮线程数 = min(K, floor(剩余可探索预算 / factor))
- 若 `剩余可探索预算 < 1.5 × factor × 2` → 不再开新轮，转收敛
- 剩余时间 < 15% deadline → 不再开 wildcard，只加深，转入收敛

## 收敛执行

触发任一收敛条件后：

1. 汇总 findings + map → 写 `report.md`（`report-template.md`）
2. `ledger.json` 记录最终账本
3. 检查报告五层齐全后向用户交付
